2.3.2 Wednesday Afternoon Exercises

Wednesday Afternoon Lecture

  1. Get set up with vsociety-find from lecture.

  2. Write vfamily*-kind which takes a vfamily* and a string for a name, it produces either a string for the kind of the named animal or false if no animal in the vfamily has the given name.

  3. Write vfamily*-move, which takes a vfamily* and an iworld and produces a vfamily* where all animals have moved to the given iworld.

  4. Optional: Write vfamily*-reunion, which takes a vfamily* and a string, and produces a vfamily* where all descendants of the animal with the given name move to that animal’s current home.

  5. Optional: Write vfamily*-add, which takes a main vfamily*, a name string for an animal already in the vfamily*, and a new vfamily*. The result should be a vfamily* like the main one, but with vfamily* added as a child of the named animal.

  6. Optional: Write vfamily*-move-mails, which is analogous to vfamily-move-mails.

  7. Optional: Write vsociety-reunion-msg, which is analogous to vfamily-reunion-msg.

  8. Optional: Create a universe that is like the vfamily one, but that uses a vsociety.

    When adding a child in vsociety-new, add it as a new animal to the vsociety’s main list-of-vparent, instead of adding it as a child of an existing animal.

  9. Optional: Implement vsociety-mate, which takes a string for an animal name and either “mates” it with a animal named in the vsociety’s waiting list or adds it to the list. The result should be a bundle with the new vsociety and, in the case of successful mating, a message to add an animal to a world.

    To “mate” two animals, they should both be of the same kind. Then a child should be added to one of the mated animal’s lists of children (even though it takes two to make a new animal, only one takes parental responsibility), while the previously waiting one is removed from the waiting list.

  10. Optional: Extend the client so that an "m" key sends a message to the server than an animal is ready to mate, and then implement mating in vsociety-msg via vsociety-mate.

    To make the game slightly more realistic, you can change the mating process so that an animal leaves its current world to join its mate’s world before the child is added.
