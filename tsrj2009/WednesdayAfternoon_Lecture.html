1.3.2 Wednesday Afternoon Lecture

Wednesday Afternoon Exercises

Generalize to multiple families and any number of children per animal:

  ; A vfamily* is
  ;   (make-parent* string string iworld list-of-vfamily*)
  (define-struct parent* (name kind place children))
  
  ; A list-of-vfamily* is either
  ;   empty
  ;   (cons vfamily* list-of-vfamily*)
  
  ; A vsociety is
  ;   (make-vsociety list-of-vfamily* list-of-string)
  (define-struct vsociety (families waiting))
