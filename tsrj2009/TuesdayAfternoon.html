2.2.2 Tuesday Afternoon Exercises

Tuesday Afternoon Lecture

  1. Write down the data definition for a list-of-vanimal.

  2. Write vzoo-scene, which consumes a list-of-vanimal and produces a scene. Combine animal scenes using the next-to helper function that you wrote this morning.

  3. Write vzoo-act, which consumes a list-of-vanimal and produces a list-of-vanimal where each animal in the list acts as before.

  4. Write vzoo-react, which consumes a list-of-vanimal and a key and produces a list-of-vanimal where each animal in the list reacts as before (all to the same key).

  5. Put your vzoo- functions together with big-bang to make a virtual zoo.

  6. Write vzoo-react2, which takes a non-empty list-of-vanimal and a key. It produces a result like vzoo-react, but the left-arrow key moves the first animal in the zoo to the end of the zoo (i.e., rotate the zoo to the left). The left-arrow key is not sent on to the animals.

    Then change vzoo-react2 so that the right-arrow key moves the last animal to the front (i.e., rotate the zoo to the right). The right-arrow key is not sent on to the animals.

    Finally, change vzoo-react2 so that only the first animal receives keys other than left-arrow and right-arrow keys.

  7. A world doesn’t have to exist alone – it can join a larger universe of worlds.

    Joining a universe requires two additions to a big-bang form: a register clause to name a universe server, and a on-receive clause to handle messages from the server.

    For the workshop, we have set up a server at "rains.cs.utah.edu". When the server sends the message starting with "cat" to your world, the world should show a new cat. Similarly, when the server sends a message starting with "cham" to your world, your world should show a new chameleon. (The server gives the new animal a name, which appears after "cat" or "cham" followed by a space.)

    1. Write vzoo-receive, which takes a list-of-vanimal and a string, and it produces a list-of-vanimal that has a new cat if the string starts "cat", a new chameleon if the string starts "cham", or just the given list-of-animal for any other message.

      You will need the substring function to get a part of a string out of a string.

    2. Connect your zoo to the universe server like this:

        (define (run-zoo loa)
          (big-bang loa
                    (on-draw vzoo-scene)
                    (on-tick vzoo-act)
                    (on-key vzoo-react2)
                    (register "rains.cs.utah.edu")
                    (on-receive vzoo-receive)))
        
        (run-zoo empty) ; in interactions

      The universe server will immediately create a cat or chameleon for your world, and then it will add a new one every five seconds or so.

      Instead of just (run-zoo), you can used the launch-many-worlds form to create multiple worlds in the same universe. For example,

        (launch-many-worlds (run-zoo empty) (run-zoo empty))

      creates two worlds.

  8. Optional: Adjust your vcat and vcham data definitions to accommodate a name, change vcat-scene and vcham-scene to display the virtual animal’s name, and change zoo-receive to extract a new animal’s name from a message.

  9. Optional: Extend zoo-receive to recognize a message that starts with "gone" followed by a space and then an animal name. For such messages, zoo-receive should produce a list-of-animal that removes the named animal.

  10. Optional: A world sends a message to the server by producing a package from a key-handling function. A package is created with make-package, which combines a string message with world that would otherwise be returned from the function.

    Extend zoo-react to handle a new key: "u". In that case, the result of zoo-react should not be a list-of-vanimal, but instead a package created with make-package. The first part of the package should be the given list-of-vanimal, and the second should be a string "reunion ‹name›" where ‹name› is the current animal’s name. Use string-append to form the string message.

    The server may respond to a "reunion" message by sending "gone", "cat", and "cham" messages to move animals from one world to another.

  11. Optional: Instead of rotating animals to select one, we can keep animals in place and add a “focus” indicator to the game.

    To support a focus, instead of equating vzoo with list-of-vanimal, create a data definition for vzoo so that it combines a list of animals with a number that indicates which animal has the keyboard focus. Change your vzoo- functions to work on the new representation.

    Then change vzoo-scene so that the scene indicates which animal has the focus. Change vzoo-react to direct keys to only the virtual animal with the focus, while the left-arrow and right-arrow keys change the focus animal (instead of rotating the animals).
