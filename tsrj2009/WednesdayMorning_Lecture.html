Wednesday Morning Exercises

Let’s keep track of a virtual animal’s children, assuming that each animal has at most two children. We’ll also keep track of each animal’s location, so that an animal can call a “family reunion” of all its descendants.

  ; A vfamily is either
  ;   empty
  ;   (make-parent string string iworld vfamily vfamily)
  (define-struct parent (name kind place child1 child2))

Write some examples.
