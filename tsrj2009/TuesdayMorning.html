2.2.1 Tuesday Morning Exercises

Tuesday Morning Lecture

  1. Write a data definition for a list of strings.

    We will think of the list of strings as representing an aquarium where we care about each fish’s color instead of weight.

  2. Write the function any-blue?, which consumes a list of colors and determines whether it contains "blue".

  3. Generalize any-blue? to the function any-matching?, which consumes a list of colors and a string, and it determines whether the string appears in the list.

  4. Write the function all-red?, which consumes a list of colors and determines whether it contains "red".

  5. Generalize all-red? to the function all-matching?, which consumes a list of colors and a string, and it determines whether the string matches all elements of the list.

  6. Write the function show-dots, which takes a list of strings and produces an image. The image should contain a sequence of dots, one for each color in the list, and in the same order as in the list.

    To create a dot image, use ellipse.

    You will need a helper function next-to, which takes two images and combines them horizontally. To do that, use overlay/xy and used the first image’s width as the “x” offset (and 0 as the “y” offset).

  7. Write the function red->blue, which takes a list of strings and produces a list of strings. Every "red" in the consumed list should be replaced by "blue" in the produced list.

  8. Write the function remove-red, which takes a list of strings and produces a list of strings, where each "red" in the input list is removed in the result list.

  9. Generalize remove-red to remove-color, which takes a list of strings and a string to remove form the list.
