The dyn.tar.gz file contains dyn.c and dyn.ss.

dyn.c is a start at an FFI by Eli Barzilay. The goal is to be able to call C code in a shared library without having to write and compile library-specific glue C code.

dyn.ss is an example that uses dyn.c to link to a speech synthesis library.

See also Eli's message on the plt-scheme mailing list and follow-ups.
