See also http://sourceforge.net/projects/schematics.

Help Wanted

There are many tools of general interest that we would like to develop for PLT Scheme, but due to limited resources, few will be implemented - unless we can interest other members of the Scheme community to develop them.

Fight the proliferation of ad hoc languages. Help to make Scheme useful for real applications. Be a part of a trailblazing research and development group. We need your participation.

PLT offers timely technical support and advice to any volunteer PLT teammember, either through direct mail or through the discussion list.

For those who want something to do, here are a few projects the we're especially interested in supporting:
  • MzScript -Implement the Windows Active Scripting interfaces for MzScheme, so it can be used in Web pages.   Contact: steck@ccs.neu.edu
  • Scsh port - Port Olin Shivers's shell language to PLT Scheme and extend it to work on multiple platforms.   Contact: sk@cs.brown.edu
  • AppleEvents - Implement an interface for receiving AppleEvents, complementing the existing interface for sending them.   Contact: mflatt@cs.utah.edu
