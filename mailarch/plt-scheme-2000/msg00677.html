Let's add another medium term point to Matthew's list: 

 * Notes: How to Use Scheme 

   MzScheme's needs "how to" notes in order to promote its use for simple
   scripting tasks (say interpreting some XML data or rendering it,
   processing directory trees, ...) and real programming (how to construct
   reusable units, how to create extensible data types, ...). 

   To address this problem, PLT will construct a set of notes on how to
   accomplish this things. 

   Your input will be appreciated. 

   Following the HtDP model, the notes will first appear on the Net, later
   in print. 

How's that? -- Matthias
