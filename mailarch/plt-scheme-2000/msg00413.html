New MrEd v102 binaries are available for the MacOS 680x0 and
PowerPC platforms.  The original Mac MrEd binaries would
not run on older versions of MacOS.  See
http://www.cs.rice.edu/cgi-bin/PLT/gnats-query-pr?query-type=number&number=1
574
for details.

The download page for DrScheme v102,
http://www.cs.rice.edu/CS/PLT/packages/drscheme/, contains
new full downloads for the two platforms.  The choices
for MacOS 680x0 and MacOS PowerPC indicate "release 2" to
distinguish these downloads from the original versions.

If you've already downloaded DrScheme v102 for these platforms, you
may want to download just the new MrEd binary.  The updated
binaries are available from the DrScheme patches page,
http://www.cs.rice.edu/CS/PLT/packages/drscheme/patches.shtml.
