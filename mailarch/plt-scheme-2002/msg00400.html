IIC, it's up to the compiler.  Generally Functional Developer does reasonably well with inferred types and type checks at compile time if compiled in 'production mode'. When compiled in 'loose' mode all checks are run time I think.

Some more info on limited types are at:

http://oop.rosweb.ru/dylan/design-notes/06-limited-types.html
