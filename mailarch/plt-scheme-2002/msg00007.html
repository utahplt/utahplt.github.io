Title: 200alpha7 for Mac OS X now exp-tagged with new binarie
As a followup to the general announcement, I'd like to announce that version 200alpha7 of Mz/DrScheme is exp-tagged for Mac OS X, and the binaries, as before, are available at <http://www.ccs.neu.edu/~clements/download/>.

NB: these compiled binaries are useful only in conjunction with an exp-tagged CVS tree.  You cannot simply download these binaries and run them.  If you're interested in more stable and more easily installed releases, please refer to <http://download.plt-scheme.org>

Mac-specific changes since 200alpha2:

* DrScheme now saves files using the UNIX convention (newlines) rather than the Classic convention (CRs)

* Fixed a crippling event-handling bug that made MrEd run 1.5x slower.
