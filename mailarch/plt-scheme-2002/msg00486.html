I've added a Windows binary for the pre-release version of SrPersist, at

  http://download.plt-scheme.org/binaries/pre-release/windows-x86/

The version currently there is for DrScheme v200alpha14.  After tonight,
when our build scripts have run, it should be the version for
v200alpha15.

Francisco Solsona found a number of problems with SrPersist and buffers
for multi-row fetch-scroll/extended-fetch.  So SrPersist buffer
management has changed a bit in recent days.
