Petter,

	SrPersist requires the files in plt/collects/srpersist, as well
as the srpmain.dll file that's available as a pre-release binary for
Windows.

	It looks like you have the DrScheme v200alpha12 distribution.
There's no SrPersist available for that distribution.  Instead, you'll
need the current CVS tree.  See:

	http://www.plt-scheme.org/anoncvs/

There's a link on that page on obtaining pre-release binaries, such as
the one for SrPersist for Windows.  If you're not on Windows, you'll
need to compile SrPersist from sources, which are in the CVS tree at
plt/src/srpersist/.

-- Paul
