> 	This matcher runs under Chez. For various reasons, it would be
> _nicer_ for me if it ran under PLT's flavor.

> http://www.cs.indiana.edu/classes/b521/DCPS/match.ss
> 
> 	Thoughts on what it would take to get it running under
> Mz/DrScheme?

The annoying problems:

 * PLT Scheme's #' produces syntax objects for list S-expression
   structure, while Chez uses plain lists. So lots of `syntax->list'
   applications have to be added.

 * `define-syntax' within the body of a `define-syntax' doesn't work in
    PLT Scheme, because there's currently nothing like
    `require-for-syntax-in-syntax'. The nested syntax declarations have
    to be lifted to another module.

 * Chez's `...' handling in templates is more forgiving than PLT
   Scheme's; the difference affects one template in the code.

Enclosed is a start at an ugly port (in .plt format). I say "start"
because I only tried it on the couple of commented-out examples in the
file, so there are surely lots of missing `syntax->list's in code that
didn't get executed.

Matthew
