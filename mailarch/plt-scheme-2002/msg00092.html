This may be just my system but I have had a problem building the 'exp'
tagged branch out of CVS. The problem was with 'mzcom'. The following files
had the wrong line endings for Microsoft Developer Studio to load them.
Changing them to standard window line endings worked fine:

src\worksp\mzcom\mzcom.dsp
src\worksp\mzcom\mzcom.dsw

The other .dsp and .dsw files in the source tree were fine.

This is with Microsoft Visual C++ V6.0 with service pack 5 installed on
Windows XP.
