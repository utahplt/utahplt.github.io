> Anybody ever tried, or investigated the feasibility of making
> a MzScheme plugin for the Web navigators?

If you're using IE under Windows, MzCOM can be used as a plugin, kind
of.

You have to send Scheme code and receive results as strings via
Javascript, which is decidedly ugly.  But it does mean you can use
Scheme code in Web pages.

At the bottom of the PLT developers' page,
http://www.cs.utah.edu/plt/develop/, there's a request for someone to
build a MzScript, which would work like Javascript.  No one's answered
the call, yet.
