Hi all,

I've released some code on Sourceforge that I've been
kicking around for a while.  The project is called
Schematics.  There are currently 3 file releases:

- Unit testing framework based on the XP framework. 
This is the most functional package

- Some numerical algs for random processes (uniform,
gaussian, discrete)

- Schemedoc - javadoc for Scheme.  It currently uses
the default Zodiac vocab which dies on an xxxr.ss
unit.  With a new vocab or parser it should work.

Hack & enjoy.  I'm not too sure how Sourceforge works,
but I think if you want to join the project you have
to email me and I'll add you.  There are no specific
goals, other than to generate useful libraries of code
for PLT Scheme.

cya,
