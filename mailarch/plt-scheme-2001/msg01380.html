I think Matthias is talking about a feature of JScheme (formerly known as SILK) that amounts to  "Scheme Server Pages": one writes a page of XML of the form <xml> ... <scheme> some text </scheme> ... </xml>

The text inside any <scheme>...</scheme> tags is evaluated as scheme code.

Take a look at the papers by Hickey et al. in the XML and Web Programming section and the Implementing Scheme in Java section of my online bibliography:
http://library.readscheme.org/page7.html#xml-web
http://library.readscheme.org/page8.html#scheme-in-java
