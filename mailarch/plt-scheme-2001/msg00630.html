> OK, this looks more like an ODBC installation problem, doesn't it?

	UnixODBC may be installed correctly, but it seems to be
unconfigured. Compiling and installing that software is not enough, it
needs to be configured before it can be used.

	The first thing to do is to run ODBCConfig as root and declare
installed drivers and drivers configurators, this is done under the
Drivers tab. Add an entry for each installed driver, for each you must
at least give it a namem choose the driving and setup library. For
postgres the libraries are respectively libodbcpsql.so and
libodbcpsqlS.so.

	Then, as an unprivileged user, you must declare data sources,
one for each database, use the User DSN tab. For each DSN you must
declare a name(the data source name), a driver, a database server
hostname (may be localhost), and a database name. This can also be
done as root, under the System DSN tab if your data sources are to be
accessed by several users on the same system.
