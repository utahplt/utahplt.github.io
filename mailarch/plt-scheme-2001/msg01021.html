Jon Fernquest, posting to comp.lang.scheme, is
preparing a port of the Perl Cookbook to Scheme.  He
will be posting his chapter on string manipultion
shortly.  

If you want to do lots of string manipulation in
Scheme there are some very nice abstractions embodied
in the awk macro ported from Scsh.  This is part of
the MzScheme distro.  I've port a bit more code from
Scsh to read and write CSV files and other infix
delimited formats.  It's in the data/ directory of the
CVS server at schematics.sourceforge.net.
