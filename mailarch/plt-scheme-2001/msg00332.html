New on Schematics
(http://sourceforge.net/projects/schematics/) is
SRFI-1, the list library.  Get it before it starts to
smell!

As always, if you want to hack any code on Schematics,
you are more than welcome.

Currently online (in order of completeness of
implementation) are implementations of:
- SRFI 1 - list library
- Unit test framework based on the XP framework
- Schemathics - some numeric algorithms
- Schemedoc - Javadoc in Scheme.

Drop me an email if you want to be added as a
developer on the project, or if you have any
suggestions or comments.
