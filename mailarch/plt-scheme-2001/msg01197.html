  • Date: Fri, 9 Nov 2001 13:53:05 -0700 (MST)

An alpha version of a parser-tools collection for use with PLT Scheme
v199 is now availible from the plt-scheme CVS repository.

This collection provides tools comparable to the usual
"lex" and "yacc".  Additionally it is well-integrated with the
mzscheme module system.

-Scott Owens
