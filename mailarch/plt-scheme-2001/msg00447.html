I just released a new version of Help Desk that works in 199.8. It is 
tagged with the v200 tag. These are the newly tagged directories:

    plt/collects/help
    plt/collects/framework
    plt/collects/browser
    plt/collects/setup
    plt/collects/net
    plt/collects/defaults
    plt/teachpack/htdp/Docs (not neccesary to update this one)


You will need to update them with the "-d" flag to "cvs update" to 
get the new subdirectories.

Once you have done that, delete your copy of plt/collects/doc/ and 
start Help Desk to download the latest one. (You will need to restart 
Help Desk after you have done that).

Robby
