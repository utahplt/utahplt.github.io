The next internal release of DrScheme will have support for changing
the language of the GUI to any language that can use the Latin-1
character set. So, we are looking for volunteers to help us translate
DrScheme's GUI -- we are particularly interested in German and Spanish
speakers who would be able to help with this (we already have French
covered).

There is a single file that contains about 400 strings in English (for
the moment, but it may grow). The job is to produce an equivalent file,
but in another language.

If you can help, please contact me.

Thanks!

Robby
