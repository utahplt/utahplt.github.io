Kirill Lisovsky wrote a paper on "Scheme program source code as
semi-structured data." You can find it here:

     http://kaolin.unice.fr/Scheme2001/

His home page contains many xml tools (as well as the tool described in tha
above paper). In fact, he also has a PLT port of oleg's SXML tools, which
are quite good. His home page is here:

     http://www196.pair.com/lisovsky/

Oleg's original SXML tools, and some documentation describing their use, is
here:

     http://www.lh.com/~oleg/ftp/Scheme/index.html

(The official SXML stuff is now up on SourceForge.)
