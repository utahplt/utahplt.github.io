   Please, correct me if I am wrong.  By using the stepper, it seems that
   DrScheme do not handle tail recursion properly for `or'.  Is this a bug?

   Here is an example:

     (define (list-or l)
       (if (null? l)
	   #t
	   (or (car l) (list-or (cdr l)))))

     (list-or (list #f #f #f #f #f #f #t))
