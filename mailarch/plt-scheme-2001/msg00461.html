Announce: digest extension version 1.0 alpha 1 is available for public
review, this is the first release.

This software package is an extension library for the MzScheme
interpreter. It provides an interface to Ronald Rivest's reference MD5
implementation as published in RFC 1321.

Your help is needed to test this extension on all platforms supported
by DrScheme. It currently works on FreeBSD systems. Feedbacks to <scm
at phoe.frmug.org> are appreciated.

More information and a plt archive is available at
<URL:http://www.bsd-dk.dk/~elrond/scheme/digest/>. Distribution is
made under the terms of a Berkeley license.
