**** Announcement Music/Midi with mzscheme ****
 
All non-real-time functions of MidiShare are implemented on windows and the package is downloadable at :
http://www.cs.utah.edu/plt/develop/
in multimedia section
 
This portage allow whoever to use midifile in his developement (loop part allowed) and
can also get the power of the midishare library all in hand. I need your help for the
port of real-time functions (mzscheme threads knowledge is needed).
 
Grame allow us a CVS server for further work :
 
http://cvs.grame.fr/cgi-bin/midishare-cvs/lang/mzscheme/
 
Instruction for code download is here :
 
http://www.grame.fr/MidiShare/SCPP/dev.html
 
Contributors are welcome : a begining preliminary Linux port is also in work....)
