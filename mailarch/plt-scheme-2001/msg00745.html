I forgot to mention: it is now possible to add languages to DrScheme. 
In fact, except for the non-debugging mzscheme and mred languages, 
none of the languages that DrScheme provides are "built-in". They are 
all implemented as tools. See the tools manual for details on how to 
add your own languages to drscheme.
