Intrepid Scheme hackers (that means you!) are invited
to download the v0.1 release of the MoshiMoshi wiki
from http://sourceforge.net/projects/schematics  

A Wiki is a collaborative web forum that allows users
to edit pages using a simple text based language.  The
leading example of the technology is the first Wiki at
http://c2.com/cgi-bin/wiki?WelcomeVisitors

This release only allows viewing of files.  Editing is
not yet supported but is coming soon (most of the
functions are there, I just need to sort out the page
flow).  MoshiMoshi requires the PLT Web Server.

There have been a bunch of other changes at
Schematics:  a new release of the math code
Schemathics (thanks to Stephan Houben) and you'll find
documentation for the test framework, scmunit, in CVS.

Enjoy!
Noel
