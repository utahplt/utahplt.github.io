The stepper was reoganized a few days ago which may have caused problems for
anyone who has used the CVS archive since then. The stepper is no longer a
tool; it has been integrated directly into drscheme. So, this means that the
directory:

  PLT/collects/drscheme/tools/stepper/

is no longer relevant. Since it has no files in it, you should pass the -P
flag to cvs so the directory is deleted (and then drscheme will start up
okay):

  % cvs update -P plt

If you do not do this, DrScheme may fail to start up.

Robby
