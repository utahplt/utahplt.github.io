Patches are available for PLT Scheme (DrScheme) v102 and 
MysterX v102.

Both patches may be obtained from 

  http://www.cs.rice.edu/CS/PLT/packages/patches.shtml

For PLT Scheme (DrScheme), the patch contains these 
changes:

  Improvements: 

   Stepper: the stepper may be reduced from its initial 
   size to as little as 300x150 pixels, if desired.
   Earlier versions of the stepper set the minimum at 500x500 pixels. 

  Fixes: 

   DrScheme: plt/collects/defaults/prefs.ss can set 
    site-specific default preferences. 
   Zodiac: fixed macro-processing bug reported in PLT Scheme 
    mailing list, see
   (http://www.cs.utah.edu/plt/mailarch/plt-scheme-2000/msg00719.html)

For MysterX, the patch contains these changes:

  Improvements: 

   Added synonyms cci/coclass for cocreate-instance-from-coclass, 
    and cci/progid for cocreate-instance-from-progid;
    com-all-coclasses, com-all-controls return sorted lists
   Added procedure mx-version 

  Fixes: 

   Fixed bug when methods, properties return NULL COM objects
