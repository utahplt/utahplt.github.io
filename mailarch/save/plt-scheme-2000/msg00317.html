Francisco Solsona has created a Scheme-based query system
that works with the existing SrPersist ODBC extension 
for PLT Scheme.  A beta version is available at 

  ftp://abulafia.fciencias.unam.mx/pub/solsona/schemeql.tgz

I'm encouraging people to download and try it out.  You 
can send any comments on the system to Francisco at
solsona@acm.org.

SchemeQL requires SrPersist, which you can download at 

  http://www.cs.rice.edu/CS/PLT/packages/srpersist/

-- Paul
