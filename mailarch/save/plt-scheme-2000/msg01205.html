I have two pieces of code.

If I type 

((lambda () 
    (define => #f) 
    (cond (#t => 'ok)))


I get:

    ==> ok

--------------------------------

If I type

(begin 
    (define => #f) 
    (cond (#t => 'ok))) 

I get an invalid procedure error,

Is this a bug?
