The currently exp-tagged CVS source for MzScheme and MrEd is now
version 102/12. This version is mostly minor bug fixes, and hopefully
close to the final 102 release.

Changes:

 * Fixed return vaue of `random-seed' (bug introduced in 102/9 or
   so). (PR 1434)

 * Fixed handling of file output ports on exit: file is flushed and
   closed. (Bug introduced in 102/10.)

 * X: Fixed list-box scrolling. (PR 1435)

 * Windows/MacOS: Made stdio window accept input for the initial input
   port (for `read', etc.).

 * Windows: Fixed many MDI problems. (Problems reported on this list.)

 * Added an optional string-offset argument to dc<%>'s get-text-extent
   and draw-text.

 * Changed code for MzScheme2k and MrEd2k so that it does not rely on
   interior pointers.

Matthew
