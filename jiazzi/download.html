Software

Current Release - 4.1.0

 

Version 4.1.0

Download jiazzi-4.1.0.tar.gz or jiazzi-4.1.0.zip. This version contains a number of internal and usability improvements, including tasks for invoking Jiazzi from Ant build files. This version works in conjunction with version 1.0.0 of the examples, listed below.

Version 4.0.0

Download jiazzi-4.0.0.tar.gz or jiazzi-4.0.0.zip. This is the first public source release.

Version 3 Beta

Download jiazzi3beta.jar (binaries only; no source code). This implements the Jiazzi language as shown in our AOSD 2003 paper. Some features, such as argument parameters, do not yet work. There are also some issues with arrays.

Version 2.2

Download jiazzi-distrib22.tar.gz (binaries only; no source code). A J2SE (JDK 1.2+) runtime is required. A version of ANTLR 2.7.0 is included in this binary release, which Jiazzi uses for parsing. Includes a tutorial. Note that the user's manual is a separate download below.

Examples

Version 1.0.0

Download jiazzi-tests-1.0.0.tar.gz or jiazzi-tests-1.0.0.zip. This package contains a set of Jiazzi applications that are designed to demonstrate and test Jiazzi. This package is intended to work with Jiazzi 4.1.x. In the near future, these example applications will be integrated into the main Jiazzi software distribution.

Documentation

Jiazzi Manual

Download jiazzi-manual.pdf. Includes instructions on how to use Jiazzi 2.2 and a tutorial to get started. Note that the manual is somewhat out of date for more recent versions of Jiazzi. An update is in the works.
